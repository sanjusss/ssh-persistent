# 连接排查与运行机制

连接失败、会话无响应、输出异常，或需要调整运行目录和空闲超时时读取。先查看命令给出的错误及日志路径，再按下表确定相关文件。

## 命令引号

`exec` 会将收到的命令参数用空格拼接，再交给远端 shell 解析。本地 shell 已经移除的引号不会自动恢复。下面示例中的 `S` 指向技能目录中的 `ssh-mux.sh`。

直接写 `$S exec A awk '{print $1}' /tmp/data.txt` 时，保护程序内容的单引号会在本地被移除。应将完整远程命令作为一个参数传入；本地使用双引号时，将 `awk` 字段中的 `$` 写成 `\$`：

```bash
"$S" exec A "printf 'alice 10\\nbob 20\\n' | awk '{print \$1, \$2 * 2}'"
```

复杂或多行命令优先[从本地文件执行](../SKILL.md#从本地文件执行复杂命令)，省去调用时的外层转义。

## 连接与终端机制

`jump` 模式用 `ControlMaster` 建立后台 SSH 连接。后续 `ssh` 和 `scp` 通过本机的套接字（进程间通信接口）使用这条连接，无需重新认证。连接文件默认保存在 `/tmp/ssh-mux-<uid>/`，其中 `uid` 是当前本机用户的数字编号。该目录必须属于当前用户，权限为 `700`，不能是符号链接。

`jump` 套接字名称为 `ssh_mux_j_<连接标识>`。连接标识根据配置文件路径和完整跳转路径计算，避免不同网络中的同地址主机共用连接。

`shell` 模式为每个“主机别名 + 会话名”启动一个守护进程，即持续在后台运行的进程。守护进程使用 `pty`（伪终端，供程序模拟终端输入输出）保持登录，自动应答各层登录提示。

中转登录使用 `exec ssh` 替换上一层 shell。目标连接退出时整条终端链关闭，后续命令不会退回中转主机执行。

多行、含制表符或较长的命令会编码为短行，逐段确认接收后再执行，避免终端补全和输入缓冲影响命令内容。

登录完成后，脚本关闭终端回显并清空命令提示符。复杂命令先在远端 shell 变量中还原，执行结束后清理变量。命令通过当前 shell 的 `eval` 执行，并在输出前后添加随机标记。结束标记与命令一起解析，不会作为密码或其他标准输入发送给程序。

`shell` 模式的文件也保存在上述私有目录，名称以 `s_<主机标识>_<会话>` 开头。主机标识根据配置文件路径和别名计算，避免别名与会话名拼接产生冲突。

| 后缀 | 用途 |
| --- | --- |
| `.sock` | 命令行工具与守护进程通信的套接字。 |
| `.ctl` | 查询状态和停止会话的控制接口，命令执行期间也能响应。 |
| `.log` | 守护进程日志。 |
| `.err` | 建立会话失败时记录的错误。 |
| `.pid` | 守护进程的进程号，仅供诊断，不用于终止进程。 |
| `.lock` | 守护进程存活期间持有的文件锁，防止重复启动。进程退出后文件可保留，锁会自动释放。 |

旧版直接放在 `/tmp/` 下的连接文件不会被新版复用。更新前可用旧版 `exit` 停止会话；已经更新时，旧会话仍按原空闲超时退出。

## 环境变量

| 变量 | 用途 | 默认值 |
| --- | --- | --- |
| `SSH_MUX_CONFIG` | 配置文件路径 | `~/.config/ssh-mux/hosts.conf` |
| `SSH_MUX_SOCKET_DIR` | 运行目录的父目录；脚本在其下创建 `ssh-mux-<uid>` 私有目录 | `/tmp` |
| `SSH_MUX_PERSIST` | 空闲多久后自动断开，单位为秒 | `600` |
| `SSH_MUX_DEBUG` | 设为非空值后，把 `pty` 收发的数据写入守护进程日志，用于排查登录问题 | 空（不启用） |

这些变量由执行脚本时的环境读取。经 `WSL` 运行时（[Windows 说明](windows.md)），在 `Windows` 侧设置的变量不会自动传入 `WSL`，需要经 `WSLENV` 转发才生效。
